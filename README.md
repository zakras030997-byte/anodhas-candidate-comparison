# Сравнение кандидатов

Лёгкая локальная программа для Mac: общие критерии вакансии, оценки с основаниями, сравнение кандидатов и решение руководителя. Данные остаются на Mac, сервер, подписка и платный API не требуются.

[Скачать для Mac](https://github.com/zakras030997-byte/anodhas-candidate-comparison/releases/tag/v1.0.0) · [Исходники](https://github.com/zakras030997-byte/anodhas-candidate-comparison)

## Возможности

- До 100 кандидатов на вакансию, 20 критериев, 3 этапов и 5 интервьюеров.
- Шкала 1–5 с описаниями уровней, веса, одинаковые вопросы и отдельные обязательные требования.
- Карточки оценщиков с основаниями, черновиками и редакциями. Пропуск не равен нулю, итог появляется только при полном наборе оценок.
- Сравнение 2–6 кандидатов: критерии, основания и условия; видны расхождения и недостающие сведения.
- История ручных решений, версии критериев без пересчёта старых карточек по новым правилам.
- CSV с предпросмотром, сопоставлением столбцов и явными действиями по дублям. Полная резервная копия вакансии в JSON.
- PDF/CSV для обсуждения с выбором включаемых контактов и заметок. По умолчанию контакты и исходные длинные заметки исключены.
- Атомарное локальное сохранение, восстановление предыдущей копии, восстановление незавершённого ввода.

## Начало работы

1. Нажмите «Создать вакансию», опишите задачи и рабочие условия.
2. Добавьте минимум три критерия. Для каждого заполните рабочий результат и вопрос, выберите важность, этап и интервьюеров. Описания уровней можно уточнить под конкретную работу.
3. Нажмите «Зафиксировать профиль». Добавьте кандидатов вручную или через «Импорт CSV».
4. В разделе «Оценки» выберите кандидата, этап и интервьюера. Внесите баллы с примерами либо объясните, что не удалось проверить. Отправьте карточку.
5. Выберите 2–6 кандидатов в таблице и откройте «Сравнение». Общий балл — арифметическое резюме введённых оценок, а не вероятность успешного найма.
6. Решение и его причину запишите в карточке кандидата. Для обсуждения сохраните PDF или CSV через «Экспорт».

«Пример» создаёт отдельную вакансию и не заменяет введённые данные. Первый запуск пустой. Незавершённый ввод редактора хранится отдельно и при следующем запуске предлагается к восстановлению.

## Оценки и ограничения

Отдельно усредняются оценки запланированных интервьюеров по каждому критерию, затем применяется важность критериев. Непроверенные темы и черновики не считаются нулями. Полнота учитывает ожидаемых оценщиков; общий балл доступен только при полноте 100%. Новая версия плана начинает оценочные карточки заново; старые версии доступны для чтения.

Поддерживаются трёхбуквенные коды валют без конвертации; USDT не поддерживается.

Зарплатные ожидания не входят в балл. Сопоставление с бюджетом возможно только при одинаковой валюте и месячном периоде и известной общей базе «до налогов» или «после налогов». Налоги и валютная конвертация не вычисляются.

Решение принимает человек. Программа не оценивает резюме нейросетью, не выбирает сотрудника автоматически, не ищет сведения в соцсетях и не отправляет письма. Резюме хранится как текст или ссылка, без вложений, OCR и автоматического разбора.

Имена интервьюеров — локальные метки. Скрытие сводки коллег до отправки своей карточки помогает порядку интервью, но не является разграничением доступа от владельца Mac или файла. Локальная история не является защищённым от подделки аудитом.

## Форматы и хранение

CSV UTF-8: сохраните шаблон в окне импорта. Обязателен столбец имени; остальные поля можно сопоставить вручную. Зарплата требует явной валюты, даты задаются как ГГГГ-ММ-ДД. Повторяющиеся имена не объединяются; совпадения по ID, email и телефону требуют решения. При обновлении изменяются только выбранные поля профиля, оценки и решения сохраняются.

JSON содержит все версии, персональные сведения, оценки, основания и историю выбранной вакансии. Импорт открывает отдельную копию, не сливает оценочные карточки. Экспорт отчёта CSV не является шаблоном для обратного импорта.

Рабочий файл находится в собственном sandbox-контейнере, Application Support/ANODHAS Candidate Comparison. Полный JSON и основания оценок могут содержать персональные сведения: храните и передавайте их осознанно. Экспорты не отправляются по сети. При удалении кандидата текущая автоматическая копия также очищается; ранее вручную экспортированные файлы остаются у пользователя. Гарантированное физическое стирание с SSD не обещается.

## Сборка и установка

macOS 13.3 и новее. Нужны Apple Command Line Tools и совместимый macOS SDK. Выполните `bash Scripts/check.sh`, `bash Scripts/check-disk.sh`, `bash Scripts/check-store.sh`, затем `bash Scripts/build.sh` и `bash Scripts/package.sh`. Глобальный SDK не переключается. Готовый DMG содержит приложение и ссылку на «Программы».

Без собственного Developer ID сборка подписывается ad-hoc; нотарификация отдельно не выполняется. Не отключайте Gatekeeper и другую защиту системы. Сборка содержит arm64 и x86_64; реально проверен запуск на Apple Silicon. Запуск на Intel и старых версиях macOS отдельно не проверялся. Выбор колонок сравнения после перезапуска нужно повторить; данные сохраняются.
